# **App Name**: CampusConnect

## Core Features:

- User Authentication: User-friendly login and signup for students and teachers, including grade and division selection. All authentication handled client side, no server.
- Personalized Dashboards: Personalized dashboards for students and teachers, displaying relevant information and a welcoming message.
- Content Display: View school notices, homework assignments, circulars, textbooks (PDF), and photo galleries. All assets will be publicly accessible via a url.
- Menu Navigation: Intuitive menu navigation for easy access to different sections and dashboards.
- User profile form: Students can fill out personal information with photo upload.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism. It evokes a sense of stability and intellect, crucial for an educational environment.
- Background color: Light blue (#E8EAF6), almost white, for a clean and spacious feel.
- Accent color: Indigo (#5C6BC0), a slightly lighter and more vibrant shade of blue, for interactive elements and highlights. This helps to draw attention without disrupting the calm atmosphere.
- Clean and modern typography optimized for readability on various screen sizes.
- Use of Material Design icons to provide a familiar and intuitive user experience.
- Responsive design that adapts seamlessly to different devices (desktops, tablets, and smartphones).
